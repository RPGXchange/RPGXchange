## Initial Pre-Release

This is the first development release of the RPGXchange specification.

### Added

- Core file structure specification (ZIP-based archives)
- Metadata system for RPGX files
- Variable storage and management system
- Formula engine with operators and built-in functions
- Resource ID naming conventions
- Semantic versioning support for files and dependencies
- File type definitions (RPGXS, RPGXC, RPGX)
- Asset directory structure
- Type system and type coercion rules
- String interpolation support
- CC BY-SA 4.0 license

## Notes

- This is a development version and subject to breaking changes
- Many planned features are not yet implemented
- Community feedback is encouraged as the specification evolves
